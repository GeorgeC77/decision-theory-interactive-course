# 前六章检查与修复记录

检查日期：2026-09-19。Python 检查使用指定的 `env_Online_Lecture` 环境。

## 本次修复

1. 第二章 IRR 求根下界原来固定为 −99.9999%。当真实根更接近 −100% 时，会错误返回该边界附近的数值。现在使用浮点可表示的下界并验证根是否在区间内；超出精度时明确返回无法可靠求解，不伪报 IRR。例如现金流 `[-1000000, 0.0001]`。
2. 第二章回收期使用固定的绝对误差判断是否回本，导致金额很小时提前判定回收，甚至给出超过项目期数的回收期。现在只有累计现值真正达到非负才计算回收期。例如 `[-1e-12, 1e-13]` 在一年内并未回本。
3. 第二章售价等于变动成本、固定成本和目标利润均为零时，原来目标销量显示“需另行判断”。现在返回零销量即可达到目标；页面仍说明所有销量利润均为零。
4. 六章共用的网页演示允许小数页码进入状态，导致所有幻灯片都不显示。现在将页码取整并限制在有效范围，无效值回到首页。
5. 第五、六章个别实验失败被局部捕获后，顶端仍可能显示“四个实验已就绪”。现在状态随计算成功、失败和输入修正动态更新，失败结果隐藏，独立实验仍可操作。
6. 第五、六章评分处理中 `Number(null)` 会把未答题视作选项 0。普通浏览器的必答校验通常会拦住空表单，但程序提交可触发误计分。现在显式区分未作答。
7. 修正第六章整合脚本重复运行时向离线打包排除名单反复加入同一条目的问题。同步更新网页与生成脚本的资源版本，避免继续加载旧脚本。

第六章上一轮修复的图表初始化错误继续通过 24 个 SVG 回归场景，涵盖初始帧、各预测期、零轮委托、负数和标签转义。
