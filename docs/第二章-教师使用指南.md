# 第二章：确定型决策分析 · 教师使用指南

面向大三经管类，4 学时，按两次 90 分钟设计。47 页演示中，第1—38页为主讲，第39—47页为附录。页数多于蓝图初步建议，是为了拆开公式、图解和易错点；附录不要求逐页讲授。

## 实验参考与关键口径

- 咖啡店模拟：A=[-20,7,7,7,7,9]，B=[-30,9.5,9.5,9.5,9.5,12.5]，单位万元。8%时NPV分别9.3101、9.9725；IRR分别23.7666%、19.4381%。8%只用于本次NPV和动态回收期，IRR与静态回收期不使用基准折现率。A的IRR更高，预算足够且互斥时B增加的价值更高。
- 增量B−A的IRR约10.3649%。低于此基准率时B的NPV更大；高于此值时A更大。但还须检查绝对NPV及预算，不能只看排序。
- A静态回收期2.8571年、8%动态回收期3.3810年，均为期内均匀回收插值；严格年末模型分别在第3、第4年末回收。
- 盈亏模拟：p=18元/杯、v=6元/杯、F=24000元/月，Q₀=2000杯/月；销量3000时利润12000元/月。产能1800时最大利润−2400元/月，保本不可达。模型假设产销相等、售价和单位变动成本固定、产品组合不变、固定成本在相关范围内不变；第12页已明示条件。
- A/B年度投资与上述月度盈亏是两组独立教学示例。不能把月利润直接乘12当作A/B给定的年净现金流；要整合成同一个经营项目，须重新说明季节性、税、折旧、投资与营运资金，并统一现金流及时间口径。
- 例2-8的成本交点300件不同于新设备的保本点380件。Q=350时新设备更优但仍亏300元。停产是否更好还要判断固定成本是否可避免。
- 例2-15：表格Y=7.2时，12%下X/Y净现值为12.7713/10.6816，选X；正文Y=7.8时为12.7713/14.0717，选Y。保留原文两种口径，未擅自认定勘误。
- 例2-12：NPV(10%)=10.1588937666，NPV(15%)=−4.0168617490万元，两点线性插值得13.58319306%，精确求根得13.47321637%。教材p.33把10%+5%×10.16/(10.16+4.02)写成13.5%，该算式实际为13.58251058%，原文此处存在算术差异，不能笼统解释为普通舍入。第22页分别写“插值13.58%”与“精确13.47%”。精确根代回NPV应接近零，插值根有近似残差。
- 更新设备按教材简化不计税：[-250,43,…,43,63]共16个时点，10%时ΔNPV=81.8493万元。旧设备可售价值190万元进入机会成本。
- 自制外购：[-48,13.8,13.8,13.8,25.8]，12%时ΔNPV=1.5416万元。教材15,407元与精确15,416.38元的末位差异需注明计算精度。
- 资本限额600万元：按NPV严格装入AFC，189.8万元；按NPVR严格装入ABHDG，257.7万元；教材初选调整ABHDC，258.5万元；枚举最优ABEH，259.6万元。教材组合不是未经调整的逐项贪心结果。
- 投资时机：10%时在六个候选时点中第4年最佳，现值约9562.19万元；0%时第5年最佳。

## 附录中的概念与适用条件

- 第9页的“等间隔、等额、期末发生”约束针对普通年金换算，不应泛指单笔P/F公式。
- 第20页明确“折现率上升时，本例NPV下降”，单调性依赖常规投资现金流，不能推广至任意现金流。
- 第41页：ERR显式按外部基准利率将后续净收益归集到期末；IRR按原现金流NPV=0定义，其求根不要求所有中间现金流实际按IRR再投资。不要将项目IRR与投资者全部财富的复合增长率混为一谈。概念辨析参考[Magni与Martin原文](https://mpra.ub.uni-muenchen.de/83889/1/MPRA_paper_83889.pdf)。单笔期初投资的ERR闭式不应直接套入分期投资案例。
- 第42页补齐教材p.35四类静态收益率的具体分子分母，见下表。它们均不折现；NPVR则以NPV除以投资现值，不能混同PI。

| 指标 | 分子 | 分母（教材本式） |
|---|---|---|
| 全部投资收益率 | 年利润＋折旧与摊销＋利息支出 | 全部投资额 |
| 权益投资收益率 | 年利润＋折旧与摊销 | 权益投资额 |
| 投资利税率 | 年利润＋税金 | 全部投资额 |
| 投资利润率 | 年利润 | 权益投资额 |

本教材“投资利润率”分母写权益投资额；其他教材或规范可能采用不同定义，教学时须明确本表是教材口径，避免仅按同名指标混比。

- 第43页：恒定正增量下，差额回收期=期初额外投资/年度净现金流增量。仅当两方案收入/服务相同且只有经营现金支出发生差异时，才化为ΔI/(C小−C大)；C不包含折旧等非现金费用。增量随年变化时应逐期累计。
- 第44页：原始现金流依时点0—6为[-6000,-4000,3000,3500,5000,4500,4000]万元。静态3.7年；10%下第4年末缺口1112.355713万元，第5年折现流入2794.145954万元，动态4.398102222年。年末集中发生时分别在第4、5年末回收。

## 教学评价

M2正文约2页，附现金流表和计算附件。口径与假设30%、计算及核验30%、约束与边界25%、表达15%。每人必须独立解释一笔现金流、一个阈值和一个方法局限。

网页提供六题即时反馈，正确选项依次为B、B、B、B、C、B。测验不自动提交；教师可要求提交解释而非分数截图。课堂角色轮换，学生使用vibe coding后须提交“模型—代码—独立核验—修正”记录。
