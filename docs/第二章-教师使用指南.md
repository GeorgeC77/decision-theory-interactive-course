# 第二章：确定型决策分析 · 教师使用指南

面向大三经管类，4 学时，按两次 90 分钟设计。47 页演示中，第1—38页为主讲，第39—47页为附录。页数多于蓝图初步建议，是为了拆开公式、图解和易错点；附录不要求逐页讲授。

## 实验参考与关键口径

- 咖啡店模拟：A=[-20,7,7,7,7,9]，B=[-30,9.5,9.5,9.5,9.5,12.5]，单位万元。8%时NPV分别9.3101、9.9725；IRR分别23.7666%、19.4381%。A的IRR更高，预算足够且互斥时B增加的价值更高。
- 增量B−A的IRR约10.3649%。低于此基准率时B的NPV更大；高于此值时A更大。但还须检查绝对NPV及预算，不能只看排序。
- A静态回收期2.8571年、8%动态回收期3.3810年，均为期内均匀回收插值；严格年末模型分别在第3、第4年末回收。
- 盈亏模拟：p=18元/杯、v=6元/杯、F=24000元/月，Q₀=2000杯/月；销量3000时利润12000元/月。产能1800时最大利润−2400元，保本不可达。
- 例2-8的成本交点300件不同于新设备的保本点380件。Q=350时新设备更优但仍亏300元。停产是否更好还要判断固定成本是否可避免。
- 例2-15：表格Y=7.2时，12%下X/Y净现值为12.7713/10.6816，选X；正文Y=7.8时为12.7713/14.0717，选Y。保留原文两种口径，未擅自认定勘误。
- 例2-12：精确IRR为13.4732%，教材插值约13.5%。单根常规现金流求根后必须代回NPV验证。
- 更新设备按教材简化不计税：[-250,43,…,43,63]共16个时点，10%时ΔNPV=81.8493万元。旧设备可售价值190万元进入机会成本。
- 自制外购：[-48,13.8,13.8,13.8,25.8]，12%时ΔNPV=1.5416万元。教材15,407元与精确15,416.38元的末位差异需注明计算精度。
- 资本限额600万元：按NPV严格装入AFC，189.8万元；按NPVR严格装入ABHDG，257.7万元；教材初选调整ABHDC，258.5万元；枚举最优ABEH，259.6万元。教材组合不是未经调整的逐项贪心结果。
- 投资时机：10%时在六个候选时点中第4年最佳，现值约9562.19万元；0%时第5年最佳。

## 教学评价

M2正文约2页，附现金流表和计算附件。口径与假设30%、计算及核验30%、约束与边界25%、表达15%。每人必须独立解释一笔现金流、一个阈值和一个方法局限。

网页提供六题即时反馈，正确选项依次为B、B、B、B、C、B。测验不自动提交；教师可要求提交解释而非分数截图。课堂角色轮换，学生使用vibe coding后须提交“模型—代码—独立核验—修正”记录。
