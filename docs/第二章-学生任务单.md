# 第二章任务单：条件已知时的投资选择

本章4学时。项目M2沿用校园咖啡店，数据是教学模拟。也可替换为有来源的真实案例，但必须明确假设。

## 课前

1. 画[-100,110]的现金流时间轴；解释10%折现率下为何NPV=0。
2. 写出收入、利润和净现金流的一项区别。
3. 读教材p.17—24；第二次课前读p.29—41，准备一处指标或数据冲突的讲解。

## 实验2：盈亏

p=18元/杯，v=6元/杯，F=24000元/月，初始产能4000杯/月。

1. 手算盈亏点与利润12000元的目标销量。
2. 将产能降至1800，记录最大可实现利润，提出一项改变条件的措施。
3. 令p=v，解释为何不存在通常的保本交点；再令F=0，说明特殊情况。

## 实验3：投资比较

B=[-30,9.5,9.5,9.5,9.5,12.5]，与A互斥、同寿命。

1. 在8%下比较NPV、IRR和回收期，解释排序差异。
2. 调节折现率寻找NPV排序切换点；列出B−A的现金流。
3. 分别在预算20、30、50万元下推荐；再切换为独立方案，解释为什么结果可能改变。
4. 固定12%，切换教材例2-15的表格7.2和正文7.8，记录数据差异怎样影响结论。

## 案例挑战与翻转课堂

任选一项，用4分钟讲解，接受2分钟改参质询。

- 预算600万元时，比较严格NPV排序、严格NPVR排序、教材初选调整与枚举最优组合。为什么比率排序不能保证最优？
- 投资时机：资金成本10%与0%时，最佳开采年份是否相同？为什么最大未来收益不一定是最大现值？
- 自制外购：复算[-48,13.8,13.8,13.8,25.8]，解释营运资金和残值的时点。

## M2提交与AI使用

正文约2页：数据来源与假设、现金流表、指标与盈亏分析、预算产能检查、推荐及切换条件。附计算附件，可从网页导出逐期CSV和学习记录。

允许AI辅助编程，须先自行写模型。至少用单期、零利率和寿命内未回收三个例子独立核查；保留一处发现问题及修正记录。不要仅提交工具截图。

评分：口径30%、计算30%、边界25%、表达15%。章末题分层选做：1/6（等值）、2/7（盈亏）、3/4/5/8（指标）、9/10（综合）；题干“获利”等口径若不明确，先声明假设。
