# 第六章学生任务单：今天的选择如何影响明天？

本章8学时，第13—16次课。使用本章网页四个实验；先写预测，再改参数，再解释结果。以下成果并入现有M1—M6项目档案，不重复提交四份实验报告。

## 课前准备

- 第13次前：读教材p.167—174，画一条“行动—观察—再行动”的时间线。
- 第14次前：算(1,0)×[[.8,.2],[.4,.6]]，解释每行、每列。
- 第15次前：先独立为小组候选方案排序，暂不交流；阅读NGT/Delphi流程。
- 第16次前：提交小组短展示和可复现附件，准备一个可现场修改的参数。

## C6-E1 从未来倒推今天

1. 保持默认三期，初始完好，收益5/1、整备费2、终值0。只看当期收益会怎样？先写预测。
2. 点击“倒推一层”，逐格记录剩一期、两期、三期的两种状态价值和动作。
3. 写一条最优路径，再补齐该路径未经过的状态对应动作。保留并列。
4. 改成两期，或让完好设备有残值。解释哪一个候选动作的“后续价值”发生了变化。

提交：模型五部件、终端条件、一格手算、完整策略、一次改参解释。

## C6-E2 试营业与扩张

1. 默认先验.5、敏感度/特异度.8。手算信号概率和后验概率，分清P(信号|需求)与P(需求|信号)。
2. 写好信号、坏信号后的动作，核算每条路径是否完整扣除了投资和试验费。
3. 将试验费改为6、8万元；解释临界点的并列。再载入教材例6-3，检查页面单位为万元。
4. 切换CARA模式，说明先取效用再求期望的原因。不要把货币EVSI与效用值直接比较。

提交：条件策略、根节点比较、信息费用临界点及一个解释边界。

## C6-E3 状态转移实验室

1. 固定不投广告，逐年推进至第2年，独立手算畅销概率。
2. 使用默认教材数据，写最后一年滞销状态的两个Q值。再解释剩两年时后续价值如何进入递推。
3. 比较一直不投、一直投、按状态调整；说明初始状态、经营年数、折现因子、终值与收益时点。
4. 将广告费从15改为5或30，再改终值；记录一格策略是否改变以及原因。
5. 选两年小例子，用前向枚举16张完整策略表，与逆向递推交叉核验。

提交：转移矩阵、策略表、向前核验、两项敏感性变化。概率向量表示群体比例或不确定性；一家店每期只实现一种状态。

## C6-E4 小型决策委员会

1. 用匿名编号收集完整A/B/C排序，先保存讨论前快照。
2. 比较相对多数、绝对多数、Condorcet、Borda；报告并列、循环或无胜者，不强行挑唯一结果。
3. 用NGT流程讨论一个明确争议，再更新排序；保存新证据、未解决分歧和修改理由。
4. 看委托实验的收敛与振荡，解释“每行和为1”为什么不足以保证意见一致。
5. 比较讨论前后W，说明它度量什么、不能证明什么。若成员数变化，单独记录。

提交：前后排序、两种规则的结果、讨论过程、责任人。导出JSON同时保存快照与项目笔记。

## M6最终交付

主报告8—12页，整合已有档案，建议内容为：

1. 问题、目标、决策者与方案。
2. 数据说明书：数值、单位、时间粒度、来源、假设、版本；区分事实/估计/偏好/模拟。
3. 适用的主要模型与关键结果，说明投资、风险、概率不足、多目标各处理了什么。
4. 有限期条件策略：在何时、看到什么、由谁执行什么；终值与触发条件明确。
5. 群体意见记录、最终分歧、推荐的适用边界。
6. 复现附件与K3：A延续DEA/目标规划扩展，或B有限期递推加枚举核验；附关键AI代码修订说明。

小组角色在分析、核查、质询、讲解之间轮换。第16次每人须能解释一格策略和一个假设变化，不要求额外开发新应用。
