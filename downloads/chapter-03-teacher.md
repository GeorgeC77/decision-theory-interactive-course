## 贯穿情境及答案

咖啡店为本章新的教学模拟，金额为万元：高/低客流下不投资[0,0]，小店[8,2]，大店[16,−6]；先验[0.6,0.4]。每个数是相同研究期、相同折现率下已扣投资和经营成本的净现值，不再折现或扣投资。并非从第二章设备现金流直接推算。若学生延续M2，应为各状态分别生成现金流并折现。

| 核验项目 | 答案 |
|---|---|
| 小店/大店EMV | 5.6 / 7.2，大店期望最优 |
| 大店亏损概率 | 0.4，实际结果为16或−6，不是7.2 |
| 完全信息毛收益 / EVPI | 10.4 / 3.2 |
| 小店/大店概率切换 | p=0.5并列；p低选小店，p高选大店 |
| 敏感度与特异度均0.8 | 好报告概率0.56，差报告0.44 |
| 后验高客流概率 | 好报告6/7，差报告3/11 |
| 报告后策略 | 好则大店，差则小店 |
| 有调查毛收益 / EVSI | 8.8 / 1.6 |
| 调查费0.5后的净收益 / 净改善 | 8.3 / 1.1 |

决策树使用教材例3-8，金额万元、不折现。默认扩建费210时：好后扩建693、好后保持359.1、差后保持54.6；小店完整策略519.9，中店551.75，根节点选中店。扩建费100时小店602.4，选小店；600时小店不扩且价值269.475，根节点仍选中店。根节点切换费约167.5333，与后期扩建阈值543.9不同。图将后7年自然状态折叠为条件期望，完整概率与年收益在“展开完整条件”内。

抽样为教材例3-11，金额元，与咖啡店单位不同。有放回；θ=[.2,.1,.05]，先验[.5,.3,.2]，买的净收益[−5,5,10]，不买0。n=4时仅X=0选择购买，EVSI=.5891625。费用为n>0时固定费+n×单价，n=0不付费。最优只在0—40中枚举，不宣称无界全局最优。

效用实验比较确定5万元与各半的20/−10万元。均值同为5。k>0为严格凹、选择确定方案；k=0并列；k<0凸、选择风险方案。CE通过效用逆函数计算；不要把效用差当万元。

## 误区与追问

- 概率和为1但状态不互斥：请重新界定状态，而不只重新归一化数值。
- 报告“80%可靠”：追问给定什么状态、报告是哪一类；似然与后验不能倒置。
- 用坏消息后的估值减先验值，称信息“负价值”：改为同一后验下新旧行动的比较。
- EVSI超过EVPI：先查行动集合、信息时点、概率和成本是否混用。
- 决策树把不喜欢的自然分支删掉：随机分支必须保留概率，只有行动分支可以择优。
- 只说最大期望：追问亏损能否承担、是否有现金或其他约束。
- 效用曲线凭感觉选定：要求标注“教学假设”，实际偏好需测定与敏感性检查。
